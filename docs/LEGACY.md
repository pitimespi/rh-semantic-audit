# Historical engineering prototypes (not active RH research)

The current project investigates **only the claimed RH formalization**. Some early files were built to test the reusable semantic graph data model against an independently available Lean project. They remain in the repository for reproducibility and to avoid deleting prior commits, but they are **not active research targets**.

Archived scope, retained as fixtures:

- `examples/bitcoin_supply.json` and `examples/bitcoin_supply_proposal_linked.json`
- `audit/BITCOIN-001-SUPPLY.md`
- `contributions/bitcoin_supply_lt_maxMoney_explanation.md`
- `docs/PROVE2ME-INTEGRATION.md` and `docs/DIRECT-PROVE2ME-CONTRIBUTION.md`
- `semantic_graph/prove2me.py` and `semantic_graph/publish.py`

These are retained as *legacy code/test fixtures*, not recommendations for further work, submissions, or outreach. The underlying `semantic_graph/core.py` validator and visualization engine are generic and continue to support the RH graph.

**RH-only project policy:** Do not submit or update Bitcoin theorems or explanations on Prove2me; do not create unrelated missions; do not engage the RH verification community without authorization. No externally authenticated Prove2me requests are necessary for the present RH source-level audit.

The original Bitcoin files are not being deleted, since doing so would be an unnecessary destructive cleanup. Project navigation and newly written research should point to RH reports and RH graph assets.
